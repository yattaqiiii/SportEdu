# 🏸⚽ SportEdu - Aplikasi Pembelajaran Olahraga Interaktif

**SportEdu** adalah aplikasi pembelajaran interaktif untuk teknik dasar **Badminton** dan **Sepak Bola** dengan fitur audio narasi, animasi, dan quiz.

## ✨ Fitur Utama

- 🏸 **Teknik Badminton**: Servis, Smash, Footwork, Netting
- ⚽ **Teknik Sepak Bola**: Dribbling, Shooting, Heading, Passing  
- 🎵 **Audio Narasi**: Penjelasan suara untuk setiap teknik
- 🎬 **Animasi Interaktif**: Visualisasi gerakan teknik
- 🧩 **Quiz Interaktif**: Tebak Gambar dan Mencocokkan Gambar
- 📊 **Sistem Skor**: Tracking progress pembelajaran

## 🚀 Quick Start

### Untuk Development:
```powershell
# Jalankan aplikasi langsung
.\run-sportedu.ps1
```

### Untuk Distribusi:
```powershell
# Buat package portable (Java + Maven + App)
.\create-portable-distribution.ps1
```

## 📋 Requirements

- **Java**: 14+ (untuk development)
- **Maven**: 3.6+ (untuk build)
- **Windows**: 7/8/10/11
- **RAM**: Minimal 512MB

## 📁 Struktur Project

```
sportedu/
├── src/main/java/          # Source code
├── src/main/resources/     # Audio, images, fonts
├── pom.xml                 # Maven configuration
├── run-sportedu.ps1        # Development launcher
├── create-portable-distribution.ps1  # Package creator
├── CARA_MEMBUAT_EXE.md     # Dokumentasi distribusi
└── README.md               # File ini
```
