# Videos Directory

Place your MP4 animation files here with the following naming convention:

- `passing.mp4` - for Passing technique
- `dribbling.mp4` - for Dribbling technique
- `shooting.mp4` - for Shooting technique
- `heading.mp4` - for Heading technique
- `smash.mp4` - for Smash technique
- `netting.mp4` - for Netting technique
- `servis.mp4` - for Servis technique
- `footwork.mp4` - for Footwork technique

The application will prioritize MP4 videos over GIF animations.
If MP4 is not found, it will fallback to the animated GIF.
